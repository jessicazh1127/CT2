NUM NUM BEAT

creating the character's animation: drag the sprite into the animation window, change the samples number to change the speed of the animation
character animation setup, e.g. if run stopped, then idle
character move at a constant steady speed of 7f to the right
in character life script, restart the background music when the character dies. i added it in character life script because it's more convenient

05 — Arduino Connection

connecting Unity with Arduino input to control the gameplay
